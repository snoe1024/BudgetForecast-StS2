[b]클라이언트 사이드 모드: 게임 진행에 영향을 주지 않습니다.[/b]

[b]상점에 도착했을 때의 소지금을 추정합니다.[/b]
공개된 정보로 상점 도착 시 소지금을 [b]추정[/b]합니다. 치트 모드가 아닙니다.
모든 유물의 수입과 지출을 반영하여 파티원 전원의 소지금과 카드 제거 비용을 나란히 표시합니다.
현재 방에서 여러 선택지가 제시되면 각 선택지의 수입과 지출을 모두 표시합니다.
게임 시작 직후 모두에게 니오우에게 무엇을 받는지 묻지 않아도 이 모드로 확인할 수 있습니다.
일찍 상점에 들러도 될지, 부드러운 머리칼을 선택한 사람이 많아 피해야 할지 바로 알아보세요!

[b]기능[/b]
지도에서 앞으로 도달 가능한 상점 칸에 마우스를 올리면 다음 정보가 표시됩니다.
[list]
[*] 선택한 경로 전략에 따른 상점까지의 경로
[*] 파티원 전원의 최소 소지금과 평균 소지금 (이벤트 손실 제외)
[*] 파티원 전원의 상점 카드 제거 비용 (유물 할인 적용)
[*] 골드 관련 고대의 존재 유물이 제시된 경우 소지금 증감
[*] 골드가 변하는 이벤트에서 각 선택지와 소지금 증감
[/list]

상점 칸에 마우스를 올린 동안 다음 조작도 가능합니다.
[list]
[*] Shift를 누르는 동안 상세 정보 표시
[*] Shift + 마우스 휠로 경로 전략 변경 (총 5종)
[*] Shift + 우클릭으로 표시 중인 경로를 그려서 공유
[/list]
